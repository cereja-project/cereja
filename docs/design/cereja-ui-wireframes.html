Cereja UI: concrete initial proposals

User-selected areas for elaboration: System Information, Repository/Directory Tree, Context Search, Compress/Decompress and Download. Initial IA: Home/Dashboard, Tools/Capabilities, System, Examples, About/Diagnostics. Final acceptance remains pending review. Sample labels are fictional; real-service operations never simulate progress or cancellation. Download uses explicitly fictional TransferProgress event fixtures; those illustrate an existing data contract, not live measurements. Integrations are unbuilt and labelled Planned UI. No browser control executes a capability.

Flow specification, boundaries and validation gates. References use exact ASCII terminal dimensions. Compact fields scroll with fixed actions; the displayed first page is not the complete form. Browser disclosure and scroll controls are review aids, not implemented TUI controls.
