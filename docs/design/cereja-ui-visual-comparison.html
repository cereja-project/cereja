A persistent command composer, slash discovery and rich inline results. This is a Cereja shell, not a conversation with an agent. These are distinct visual proposals, not approved product screens.

DESIGN PROTOTYPE SYNTHETIC DATA

The review controls below are outside the proposed terminal UI. No command touches files, collects hardware or makes a request. Example telemetry is fixed fixture data, not a simulated running transfer.

A. Ledger

An open reading surface: a fine cherry stem ties a command to its inline result. Sections use whitespace and typographic weight, not repeated boxes. A quiet composer rule anchors the bottom. No saved command history is implied.

B. Workbench

A bounded current-view canvas: visible title edges, compact sections and a contextual inspection column on wide terminals. A recessed command dock remains below. The same slash grammar replaces the active canvas.

Click a composer, type /, use Up/Down and Enter to insert a command. Enter again opens its view. Tab also completes a command. Escape dismisses suggestions. With no suggestions, Tab switches focus between composer and content; PageUp/PageDown scroll content. F6 returns to these review controls. Try /system, /tree, /context, /examples or /help.

Shared contract, different visual treatment

  • The bottom composer is reserved at every size. Suggestions grow upward within the content budget. At 40 x 12 only the current suggestion and concise help remain visible; no output displaces the composer.
  • These states are inline content inside the same shell, not separate Loading, Empty or Error screens. System, examples, catalogue and diagnostics share navigation and focus rules.
  • Determinate fixture: 768 bytes received of a known 1,536-byte total (a snapshot present in the local probe). Unknown-duration work stays indeterminate. No fabricated speed, ETA or unsupported Cancel. The activity shimmer changes only a fixed placeholder region and stops when motion is off.
  • One background operation keeps input/navigation responsive. The plain snapshot has no interactive input, cursor control or animation. Color capability changes preserve text labels and selection markers.
  • Both alternatives use a typographic Cereja signature and restrained cherry accent. Neither introduces a new official logo, chatbot persona, saved history or AI functionality.
  • HTML reproduces terminal-cell composition for review. It does not validate actual emulator glyphs, terminal input, restoration, screen-reader behavior or production performance.
